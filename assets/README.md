# Assets Folder

This folder contains all the images and media files for your portfolio.

## Required Images

### Profile Photo
- **Filename**: `profile.jpg` (or `profile.png`)
- **Size**: 400x400px (square format recommended)
- **Description**: Your professional headshot or profile photo

### Project Images
- **Filenames**: `project1.jpg`, `project2.jpg`, etc.
- **Size**: 800x600px or similar aspect ratio
- **Description**: Screenshots or images of your projects

## Image Guidelines

1. **File Formats**: JPG, PNG, WebP, or SVG
2. **File Size**: Keep images under 1MB for faster loading
3. **Quality**: Use high-quality, professional images
4. **Naming**: Use descriptive, lowercase filenames without spaces

## Default Images

- `default-avatar.svg`: Placeholder for profile photo
- `default-project.svg`: Placeholder for project images

These will be used if your actual images are not found.

## Adding Your Images

1. Add your profile photo as `profile.jpg`
2. Add project images as `project1.jpg`, `project2.jpg`, etc.
3. Update the image paths in `data.js` to match your filenames
4. Refresh your website to see the changes

## Tips

- Optimize images before uploading (use tools like TinyPNG)
- Use consistent aspect ratios for project images
- Consider using WebP format for better compression
- Always keep backup copies of your original images
